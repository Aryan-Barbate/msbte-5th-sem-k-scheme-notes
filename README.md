## ✨ What's Inside This Vault?

This repository contains complete, structured study notes prepared for **MSBTE 5th Semester (K-Scheme)** theory and practical preparation across **3 core subjects (210 total theory marks)**:

- **Master Maps of Content (MOCs)** — Central dashboards per subject with PYQ priority tiers, syllabus weightage, and cross-unit links.
- **Complete Unit Notes (Units 1–5)** — Detailed conceptual breakdowns, difference tables, ASCII/Mermaid/PNG diagrams (130+ visual diagrams), and KaTeX formulas.
- **Formula & Numerical Solvers** — Step-by-step solved numericals (CPU Scheduling Gantt charts, Banker's Algorithm, Page Replacement, COCOMO, Function Points, CPM/PERT, Defect Metrics, etc.).
- **Important Question Banks & Model Answers** — 2M, 4M, and 6M exam-oriented answers mapped to MSBTE paper patterns (**W25** & **S26** audits included).
- **Practical & Command Manuals** — Linux commands, MongoDB CRUD/aggregation cheatsheets, and Software Testing / UML practical references.
- **Mobile Study Hub & Flashcards** — Portrait-friendly quick revision hub and flashcards for last-minute exam prep.

## 🖥️ Obsidian Setup Guide (Desktop)

These notes are built as a connected **Obsidian Vault** using wikilinks (`[[...]]`), callout blocks, Mermaid diagrams, and KaTeX math. For the best reading and study experience, open this repository in **Obsidian Desktop**:

### Step 1: Install Obsidian
1. Download Obsidian (free for personal/educational use) from **[obsidian.md/download](https://obsidian.md/download)**.
2. Install it for your OS (**Windows**, **macOS**, or **Linux**).

### Step 2: Download the Repository
Choose **either** option:

- **Option A — Using Git (Recommended, easy to pull updates):**
  ```bash
  git clone https://github.com/Aryan-Barbate/msbte-5th-sem-k-scheme-notes.git
  ```
- **Option B — Download as ZIP (No Git required):**
  1. Click the green **`<> Code`** button at the top of this GitHub page → **`Download ZIP`**.
  2. Extract the ZIP to a permanent folder (e.g., `Documents/msbte-5th-sem-k-scheme-notes`).
  > ⚠️ **Important:** Make sure you select the **inner root folder** that directly contains `.obsidian/`, `Operating System/`, `Software Engineering and Testing/`, and `Advanced Database Management/` — not an outer wrapper folder.

### Step 3: Open the Folder as an Obsidian Vault
1. Launch **Obsidian**.
2. On the welcome screen (or click the **Open another vault** icon in the bottom-left), choose **Open folder as vault** → click **Open**.
3. Browse to and select the `msbte-5th-sem-k-scheme-notes` folder.

### Step 4: Enable Themes & Community Plugins
When opening the vault for the first time, Obsidian will show a security prompt asking whether to trust the vault's author for community plugins:
1. Click **Trust author and enable plugins** *(if you skip this, you can enable them later in **Settings → Community plugins → Turn on community plugins**)*.
2. Check **Settings → Appearance**:
   - **Active Theme:** `Things` (pre-installed; `AnuPpuccin` and `Minimal` are also included — switch anytime using **Theme Picker**).
   - **CSS Snippets:** `graph-styler-cyber` is enabled by default (14 `graph-styler-*` themes plus `mobile-learning.css` are included in `.obsidian/snippets/`).
3. **Included Community Plugins:**
   - **Omnisearch** — Fast full-text search across all notes & PDFs.
   - **Mind Map** — View headings as interactive mind maps.
   - **Editing Toolbar** — Quick formatting toolbar.
   - **Graph Styler** & **Style Settings** — Visual styling for the Graph View & themes.
   - **Theme Picker** — Quick theme switching from the status bar.
   - **OpenCode** — AI/code integration plugin.
   - *(Optional)* **Harper** (grammar checker) has its large binary excluded via `.gitignore` to keep the repository lightweight. If you want grammar checking, simply reinstall/update **Harper** from **Settings → Community plugins → Browse**.

### Step 5: Desktop Study Tips & Shortcuts
- **Switch to Reading View (`Ctrl + E` / `Cmd + E`):** Renders all callouts, tables, KaTeX equations, and Mermaid diagrams cleanly.
- **Quick Switcher (`Ctrl + O` / `Cmd + O`):** Jump instantly to any unit, formula solver, or question bank by typing its name.
- **Graph View (`Ctrl + G` / `Cmd + G`):** Visualize how topics connect across OSY, SET, and ADMS.
- **Local Search (`Ctrl + Shift + F`) or Omnisearch:** Search for any MSBTE keyword (e.g., `COCOMO`, `Banker`, `FLWOR`, `MongoDB`).
- **Export to PDF:** Open any note → click `•••` (top-right) → **Export to PDF** (already pre-configured for **A4** paper in `.obsidian/app.json`).

## 📱 Mobile Obsidian Setup (Android / iOS)

This vault includes `00 - Mobile Study Hub (OSY, SET, ADMS).md`, `01 - Mobile Quick Revision & Flashcards (OSY, SET, ADMS).md`, and a custom `mobile-learning.css` snippet optimized for portrait phone screens.

1. Install the **Obsidian** app from the **Google Play Store** or **Apple App Store**.
2. Copy the extracted `msbte-5th-sem-k-scheme-notes` folder onto your phone's internal storage (e.g., via USB, Google Drive, or a Git client like Termux/Working Copy).
3. Open Obsidian Mobile → **Open folder as vault** → select the copied folder.
4. Go to **Settings → Appearance → CSS snippets** and toggle **`mobile-learning`** ON for mobile-friendly callouts, tables, and sticky TOC styling.
5. Open **`00 - Mobile Study Hub (OSY, SET, ADMS)`** as your starting home screen.

## 🌐 Reading Directly on GitHub (Without Obsidian)

Don't want to install Obsidian? You can still study everything right here in your browser:
1. Use the **Subject-Wise Index** tables above to open any unit, question bank, or formula sheet directly on GitHub.
2. GitHub natively renders Markdown tables, code blocks, images, LaTeX math, and Mermaid diagrams.
3. **Note:** Obsidian-specific `[[Wikilinks]]` inside notes are plain text on GitHub and won't be clickable in-browser, and `> [!tip]`/`> [!abstract]` callouts render cleanly as GitHub alerts (`> [!TIP]`, `> [!NOTE]`) or blockquotes. For clickable cross-note links, Graph View, and Mind Maps, Obsidian Desktop/Mobile is recommended.
